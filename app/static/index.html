🎯 Quick Start

To use this API, you'll need to:

  1. Register a user at POST /register
  2. Login to get a JWT token at POST /login
  3. Use the token in Authorization header: Bearer YOUR_TOKEN
  4. Create workflows, steps, and tasks
POST /register - Create new user
POST /login - Get JWT token
GET /workflows/ - List workflows
POST /workflows/ - Create workflow
POST /tasks/{id}/transition - Change task state
GET /analytics/workflow/{id}/bottlenecks - Get metrics

🔌 Connect a Frontend

This API is ready to be consumed by any frontend application:

  • React, Vue, Angular, or any JavaScript framework
  • Mobile apps (iOS, Android, React Native)
  • WebSocket support at ws://localhost:8000/ws/workflow/{id}
  • CORS enabled for all origins in development
